# 0.4.1：硅岩反应堆辅助燃料随等级延长

目标环境为 GTNH 2.9.0-beta-3 / Matter Manipulator 0.1.55-GTNH。

大型硅岩反应堆的主燃料在配方开始时消耗；空间激发液、时间冷却液和液态空气则由原生 `onRunningTick` 每 20 tick 消耗。此前中心只延长整批持续时间，辅助材料仍按原频率消耗，导致高等级长批次消耗大量空间和时间。

现在按本批启动时的“原始持续时间 / 托管持续时间”推进辅助扣料周期。输出仍逐 tick 注入，原生激发倍率、冷却效率和材料选择保持生效。一批享受更长发电时间，同时辅助材料扣料次数保持在原始配方的水平。例如本批时长延长 24 倍时，原本每秒扣料变为约每 24 秒扣料。

已扣料周期及其输出持久化保存；重启、卸载、输出暂停后续跑不会重复支付同一周期。缺少必要液态空气而输出为零时仍等待并重试。运行中升级等级不追溯改变本批，新批使用新等级。

旧版本已运行的任务没有记录原始持续时间，不推测或追溯返还耗料；该批结束后的新配方开始使用修复逻辑。其他发电机继续使用原有托管流程。

构建与 131 项自动化测试通过。新增测试覆盖整数／非整数倍率、最大档长批次、逐 tick 输出、重复调度与重启输出恢复，使用隔离的原生控制器子类模拟扣料；尚未在完整整合包内实测。
