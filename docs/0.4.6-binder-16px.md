# 0.4.6：绑定器原生 16×16 材质

将托管绑定器从 64×64 改为原生 16×16。修正版移除手工重画的像素网格，直接从选定的 C 款透明原图等比采样，不单独移动或重画钳口、握柄及转轴。使用区域采样保留细小部件的颜色贡献；16×16 的像素预算仍会损失细节，无法逐像素还原高分辨率概念。

保留原生 8 帧呼吸动画，42 tick 循环（正常游戏速度约 2.1 秒）。基础贴图和 LabPBR 法线、材质贴图均为 16×128 的纵向帧图，帧序一致。实际自发光和泛光依赖渲染器、光影包支持及其设置；尚未进行游戏内光影实测。

原图位于 `tools/texture_sources/binder-c.png`；运行 `tools/generate_binder_texture.py` 可生成材质及 `build/binder-preview/` 内的原图对照、静态和动画预览。本次只修改绑定器材质，保留此前的托管功能。

亮度修正：对 RGB 应用 0.72 次幂提亮中间调，保持透明度和轮廓不变；灯带呼吸亮度范围从 65%—100% 调整为 80%—100%，改善暗帧辨识度。
