# 0.4.16 标记输入总成

- 物品和流体标记格显示设置的数量上限，使用 k/M/G 缩写；中键仍可修改，提示中保留当前可用量。默认显示 2.14G。
- 下方添加原版物品自动拉取按钮，左键切换自动列表，右键设置最小数量和刷新周期。沿用 GT 原版行为，切换自动列表会更新物品标记。
- 添加“放置手动物品”按钮，弹窗访问原版的一个实体手动槽；沿用原版配方消费和拆卸处理。
- 新增无线 ME 输入总成（默认 ID 32609），普通放置不绑定，Shift 放置连接收藏频道。工作台无序配方：ME 输入总成 + AE 无线接入器。
- 默认空标记和默认数量不再产生额外掉落 NBT，空总成拆下后可与新总成堆叠；配置、非默认自动拉取参数仍保留，不强行合并不同配置。

验证：离线完整 Gradle build 和回归测试通过，包含真实总成掉落 NBT 检查；未进行游戏客户端/服务器实测。
