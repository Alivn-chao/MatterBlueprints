# 0.4.15：无线版本合成配方

以下均为合成台无序配方，每次消耗一个原版方块/仓室和一个 AE 无线接入器，产出一个无线版本：

| 原料 | 产物 |
| --- | --- |
| 普通 ME 控制器 + 无线接入器 | ME 无线连接控制器 |
| ME 合成输入总线（支持流体的样板输入总成）+ 无线接入器 | 无线 ME 样板输入总成 |
| ME 输出总线 + 无线接入器 | 无线 ME 输出总线 |
| ME 输出仓 + 无线接入器 | 无线 ME 输出仓 |
| ME 输出总成 + 无线接入器 | 无线 ME 输出总成 |

无线接入器使用 AE 原生 appliedenergistics2:tile.BlockWirelessConnector。上述配方替换原来的末影之眼配方；无线控制器也不再需要额外红石。

仍适配 GTNH beta3 / GregTech 5.09.54.133，保留 0.4.14 的功能及修复。客户端与服务端均替换旧版后重启。
