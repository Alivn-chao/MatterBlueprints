# 0.4.12：无线界面崩溃修复与外观调整

适配环境仍为 GTNH 2.9.0-beta-3 / GregTech 5.09.54.133 / AE2 rv3-beta-1050-GTNH。

## 修复

- 右键无线控制器掉线：创建主界面时，MUI 的容器还未初始化，不能调用 PanelSyncManager.getPlayer()。现在直接使用 PosGuiData 提供的玩家。
- 点击“新建并连接”等按钮客户端崩溃：MUI 的 InteractionSyncHandler 会先执行客户端回调。现在通过 MouseData.isClient() 忽略本地操作，只执行服务端收到的点击。
- 生成频道列表后的潜在崩溃：动态行的连接、收藏、删除按钮改用有稳定频道 ID 的显式同步处理器注册。
- 控制器物品不可见：AE 的方块渲染器不绘制背包物品。现在给无线控制器注册同一套 AE 专用物品渲染器。

## 外观

保留 AE 控制器外壳、染色及运行动态效果；叠加 AE 原生紫色无线天线标记，在物品和已放置方块上均可辨识。运行时引用 AE 的材质，不打包复制 AE 贴图。

频道面板参考用户提供的 GTO 截图：金棕色节点标题、深色状态条、青色新建按钮、红色断开按钮、绿色已连接频道、金色收藏星标。状态文字改为客户端本地化，修复中文客户端显示英文状态的问题。

## 安装与验证

客户端与服务器均替换旧版 matterblueprints JAR，保留配置和存档。不要同时保留两个版本。

新增客户端回调及真实点击数据包回归测试，并检查主界面玩家来源、动态行注册和客户端物品渲染器注册。完整构建、Checkstyle 和全部单元测试通过。尚未在运行中的整合包内验证实际界面与渲染。
