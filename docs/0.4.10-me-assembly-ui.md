# 0.4.10：ME 总成界面与双硬盘缓存

依赖 GTNH 2.9.0-beta-3、GT5-Unofficial **5.09.54.133**、Matter Manipulator 0.1.55-GTNH。
包含 GitHub `fix/late-mixin-loader` 分支的 0.4.9-hotfix.1 启动修复，late mixin loader 保持在 `loading` 包。

## 输入总成

- 主界面上方显示物品标记，下方显示流体标记。各 16 槽，按 8 列 × 2 行排布。
- 不再显示 16 个常驻数量输入框，也不再把流体配置藏在另一个窗口。
- 鼠标中键点击对应标记槽，在单个弹窗中设置缓存量上限；悬停提示显示上限及配方可用量。
- 数量未设置时仍为 2,147,483,647（约 2.1G）；0 禁用。滚轮不会改变配置。
- 独立的定量 ME 输入总线/输入仓同步采用中键数量弹窗。
- 库存与配方结算保持原生 ME 虚拟库存逻辑，未消耗的原料始终在 AE 网中，不提前提取。

## 输出总成

- 物品硬盘槽和流体硬盘槽各一个，各自有原版缓存模式、优先级、输出检查开关及容量显示。
- 物品继续使用原版 ME 输出总线提供器；流体改用原版 ME 输出仓提供器，两个提供器共用总成的一个 AE 节点。
- 不插盘默认缓存 1,600 件物品、128,000 L 流体。插盘后的容量使用原版提供器计算，包含原版按存储类型、分区和剩余字节计算的规则，不另做简化容量公式。
- 分区过滤、缓存模式与配方输出检查遵循原版规则。普通硬盘和流体硬盘分别插入对应槽。
- 旧 0.4.9 的 16 槽流体缓存自动并入新缓存，即使旧存量超过新容量也保留，输出腾出空间后继续工作。
- 拆除时在 AE 节点有效期间尝试刷新两类输出，网络拒收的剩余缓存随总成保留。流体硬盘随总成保存；物品硬盘仍走原生物品槽的掉落处理。

## 验证

针对 .133 重新完整构建，并验证原生缓存默认容量、模拟不写入、输出空间不足拦截、配方动态空间检查和大于 int 的缓存序列化。
尚未在完整整合包内进行 GUI 与 AE 联机实测。
