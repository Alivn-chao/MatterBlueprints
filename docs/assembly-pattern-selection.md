# 装配线样板目标与重叠配方修复

适用于托管中心的装配线配方选择，不针对束流仓名称或固定配方编号。

GT 原生样板输入总成的每个缓冲区按其样板目标产物筛选已研究配方，严格比较物品、元数据和 NBT。样板倍增后的产物数量不影响识别。目标配方缺料、缺电或输出空间不足时等待，不退回其他产物的配方。闪存研究要求继续生效；空样板或不适合装配线单物品输出的样板不会扣料。

普通输入及无法提供目标产物的输入仓，按当前独立缓冲区的实际原料检查配方包含关系：完整大配方的材料不会被其小配方抢走；相同材料对应不同产物且无法区分时，均不扣料。矿辞替代、分散堆叠和流体数量参与检查。该方式不能推断所有投料意图，有歧义时应使用可读取目标的样板输入总成。

回归测试覆盖束流输入/输出仓的 beta-3 配方数量关系、闪存顺序、独立缓冲区、同料不同产物、矿辞替代、目标缺料、未研究目标以及元数据/NBT 区分。

beta-3 修复包为 `matterblueprints-0.3.28-beta3-fix2.jar`，保留 fix1 的普通装配线升压和批处理／不足 1 tick 超频修复。客户端和服务端替换旧版，不要重复安装。当前 RC-1 源码同步包含此修复。构建与自动化测试可验证代码路径，仍需在完整整合包中复测。
