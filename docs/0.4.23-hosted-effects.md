# 0.4.23：托管工作特效与螺丝刀开关

## 使用

手持螺丝刀，普通右键托管中心控制器，切换该中心所绑定机器的工作特效，聊天栏显示开关结果。Shift+螺丝刀保留配方锁定功能。

默认开启；每个中心独立保存，重启、卸载区块、拆下再放置均保留选择。配置 `machines.hostedMachineEffects` 决定未保存过选择的中心默认值。远端设备自己的隐藏渲染设置仍然有效。

正常工作时显示；短配方衔接有最多约 1 秒的熄灭延迟，避免线圈不停亮灭。手动关闭绕过延迟，控制器状态立即关闭，线圈在下一次原生更新时熄灭。

## 适配范围

基于当前构建的 GregTech 5.09.54.133 原生代码核对：

| 特效 | 本次接入 |
| --- | --- |
| 被托管控制器运行材质 | 复用原生 active 同步 |
| 超维等离子煅炉发光线圈 | 复用原生 GTCoilTracker |
| 工业切割机锯片转动 | 客户端根据 active 播放原有动画 |
| 异星铸造塔光环 | 原生渲染器根据 active 显示，仍遵守设备自己的渲染开关 |
| 工业离心机运行覆盖层、量子力场约束器运行渲染 | 原生 active 路径 |
| 电力高炉、巨型高炉、裂解机、多重冶炼炉、热解炉、大型化学反应釜、巨型合金冶炼炉等发光线圈 | 使用原生 activeCoils 的结构复用线圈状态 |

普通加工以正在使用的聚合机器组显示运行效果；矩阵煅炉按实际参与任务的成员显示，发电机按当 tick 成功推进发电的机器显示。

纳米煅炉、生物反应器、反物质锻炉、和谐之眼、诸神之锻等存在独立渲染方块或专用生命周期，本次没有为它们新增专用特效联动。其通用控制器运行材质仍可响应，但不能据此认为所有大型特效都已适配。

## 服务器开销

沿用托管中心原有的远端维护循环及已缓存机器引用，不新增世界坐标扫描。每台机器仅维护运行标记和到期 tick，使用远端世界时钟，跨维度不会混用计时。

只在状态改变时调用原生 active 更新。稳定运行时不重复创建线圈租约；短配方的熄灭延迟避免大量线圈方块来回更新。动画由客户端原有渲染路径完成。

这不是零开销保证：启停时原生线圈仍需更新方块，机器原有渲染器也可能有自己的服务端逻辑。未进行真实服务器 MSPT 测量。

特效只替换原生 onPostTick 中用于 active 与线圈的两次进度读取，不修改真实配方进度，不启动远端重复扣料、耗电或产出。中心停止刷新后，视觉租约到期熄灭；解除托管时交回原生状态管理。

## 验证

自动测试覆盖视觉租约到期、未成型熄灭、短配方衔接、手动关闭与解绑，以及 128 台机器稳定运行 1200 tick 仅在启停时产生 256 次 active 设置调用。另核对目标版本字节码中的两处视觉读取、线圈调用以及切割机和铸造塔的客户端 active 路径。

该调用次数是隔离测试结果，不代表游戏网络包实测或服务器 MSPT。实际游戏画面仍需在客户端验证。
