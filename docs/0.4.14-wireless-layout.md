# 0.4.14：无线界面排版与操作提示

- 频道名采用固定左对齐文本行；节点数量独占下一行，长名称缩略，悬停显示完整名称及连接操作提示。
- 状态框上方为“网络状态”，下方为频道名或离线状态；在线时使用深绿色背景。标题精简为源节点/终端节点，右侧显示由位置生成的简短节点标识。
- 减少空白区域，收藏和删除按钮融入频道卡片，保留悬停及按下反馈。创建、断开、翻页、收藏、取消收藏、删除都有操作提示。
- 仓室入口由 W 改为 AE 原生无线接入器物品图标。
- Shift 放置成功绑定收藏频道后，服务端向放置玩家发送“已连接无线频道：频道名”；没有收藏时提示保持未绑定。普通放置仍不绑定频道。
- 保留 0.4.13 固定同步入口，动态列表重建不会新增同步器。

客户端及服务器同时替换旧版。完整构建及同步生命周期回归通过；未在完整整合包中实测最终显示效果。
