# 0.4.5：托管绑定器呼吸灯材质

采用 C 款连接钳外形：银色钳口、深色握柄、蓝色转轴与青色灯带。修正版从原概念提取主体，等比缩放至 64×64 像素，保留修长握柄和粗钳口，不再使用初版的坐标重画轮廓。8 个亮度帧往返播放，每帧 3 tick，一个循环 42 tick（正常游戏速度约 2.1 秒）。只有灯带改变亮度。

动画使用 Minecraft 原生物品图集与 `.png.mcmeta`，关闭光影也能播放，不需要额外物品渲染器或服务端逐 tick 逻辑。

附带对齐动画帧的 LabPBR `_n`、`_s` 材质。支持物品 LabPBR 的渲染器和光影包开启对应材质选项后，可读取灯带自发光；泛光光晕取决于光影包及其设置，不保证所有光影都支持。普通渲染下仍有青色明暗动画，但不会照亮周围方块。

运行 `tools/generate_binder_texture.py` 可重新生成游戏材质以及 `build/binder-preview/` 内的静态、GIF 预览。预览展示基础材质动画，不代表光影实际泛光效果。尚未进行游戏内光影实测。
