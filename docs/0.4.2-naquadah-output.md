# 0.4.2：硅岩发电功率与时长换算

目标环境：GTNH 2.9.0-beta-3 / Matter Manipulator 0.1.55-GTNH。适用于托管的大型硅岩反应堆，其他发电机继续使用原有流程。

## 输出规则

- 无线：完成本批辅助材料结算后，发电持续 1200 个有效 tick（20 TPS 下 60 秒），将加成后的整批电量直接存入中心所有者所属无线电网。换算后的无线功率不受远端动力舱吞吐限制。
- 有线：按远端动力舱与中央动力舱额定功率中的较小值输出，名义时长为“剩余 EU / 额定 EU/t”向上取整。最后一 tick 仅输出余量。中央实际吞吐或缓存不足时暂停，多个任务共享中央输出能力，实际耗时可能增加。
- 原始配方时长及启动时等级确定本批加成，不会在运行中反复乘倍率。两种模式都使用同一份剩余电量，切换模式不增加总电量；转为无线时将剩余量重新分摊至 60 秒。
- 正常完成后输出枯竭燃料，时长不再因等级增长到数小时。

例如原本以 6.65×10¹¹ EU/t 运行 18432 秒的一台炉子，无线变为约 2.04288×10¹⁴ EU/t、60 秒，总 EU 不变。

## 时空耗料与续跑

原生硅岩燃料仍在配方启动时扣除。空间激发液、时间冷却液及液态空气按原始配方的周期数逐段结算，选择与效率仍由原机计算。结算成功的每段形成一份待输出电量，不产生额外可合成物品；结算未完成前暂不向外发电。因此需要先供应完整一批所需的辅助材料。每次最多处理 64 段，避免长配方阻塞单个 tick。

结算进度、剩余电量和无线剩余 tick 均保存到中心。普通卸载、重启、暂停与重新绑定不重扣已结算段；解除托管时这类任务留存在原中心，重新托管原位置机器后续跑，不交给原生控制器重复执行。移除中心或原机的正常存档数据仍会丢失其中任务。

0.4.1 中正在执行且包含原始时长记录的批次会自动转换剩余部分，保留已经支付的当前时空周期。更早版本缺少该记录的批次继续旧流程，下一批使用新规则。

总电量和无线入账采用大整数，超过 long 范围时也不截断；部分现有功率显示字段达到 long 上限时仅显示上限值。能量里程碑记录实际入账的完整电量。
