# 0.4.4：拆卸托管中心保留里程碑

适用于 GTNH 2.9.0-beta-3 / Matter Manipulator 0.1.55-GTNH。

托管中心控制器接入 GT 原生 `setItemNBT` 掉落保存接口，将里程碑写入控制器物品的 `mbHostProgression`。正常拆下并收回控制器物品，再次放置时，原生 GT 放置流程会通过已有 `loadNBTData` 恢复以下累计值：

- 有效工作时间 `productiveTicks`。
- 完成工作量 `workUnits`。
- 大整数能量吞吐 `energyThroughput`，不受 long 范围限制。
- 发电工作量尚不足一单位的余量 `generatorWorkRemainder`。
- 已永久解锁的煅炉燃料减免 `plasmaFuelUnlocked`。

放回后继续累计，等级和倍率依据服务端当前门槛配置计算；永久解锁标记不会因搬运而取消。无线预存余额、任务和远端绑定不写进这个里程碑物品标签；已有拆除时任务处理及无线退款逻辑继续负责这些状态。搬到新位置后需重新绑定远端机器。

请先升级客户端和服务端，再拆机器。旧版本已经掉落且没有进度标签的物品无法凭空恢复之前的数据。需要正常收回控制器掉落物；创造模式直接删除、物品被摧毁等没有保留物品的操作不属于搬运保存。

验证覆盖 GT 掉落接口接入、大整数与满级数据恢复、永久解锁、发电余量续计、原生物品标签共存，以及确保物品未导出无线资金和运行任务。完整构建及 153 项自动化测试通过，尚未在完整整合包内实测。
