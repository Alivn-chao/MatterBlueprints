# 托管中心无线供电（0.3.24-beta3）

## 两个独立槽位

- 原机器槽：放入远端机器控制器，选择托管类型，不受升级槽影响。
- 新升级槽：只接受“充能超立方体”（GT EnergisedTesseract），最多一个。升级槽旁有“无线”开关。

充能超立方体使用 GT 原版合成，运行时不消耗。旧无线升级物品不再启用无线，也不再提供原低成本合成；保留注册避免旧存档物品丢失，任务结束后手动取出换装。

## 使用

1. 按原方法绑定远端机器，把对应控制器放进机器槽。
2. 把充能超立方体放入独立升级槽，由托管中心所有者打开“无线”。
3. 安装升级后，托管中心可不放能源仓，但输入、输出、维护及其余结构要求不变。
4. 预先给中心所有者所属的 GT 无线团队电网充电。打开界面的人不会成为扣电账户。

无线模式按现有聚合任务的实际 EU/t 扣电，不受中央能源仓吞吐限制；不改变远端电压、超频、并行和特殊机器机制。普通远端仍保留用于确定等级及成型的能源仓；太空组装机仍使用模块固定电压。

关闭无线后恢复有线供电，不会自动同时从两种来源扣电。中心没有能源仓时，关闭无线会令耗能任务等待供电。无线余额不足也会暂停进度，补充后继续。无线升级只能在任务结束、预存余额退还后取出，不能由自动化管道插拔。只有中心所有者可切换无线或取出升级。

发电模式开启无线后，将实际产生的 EU 存入中心所有者所属团队电网，不同时写入中央动力舱。中央动力舱可以省略，远端的原生成型、动力舱与转子等部件仍须保留。关闭无线恢复中央动力舱输出。发电不进入消费者的预存余额，因此不参与其退款。

## 性能和存档

按聚合功耗预存最多 20 tick 的电量，短任务按剩余时间预存；余额不足整批但够一个 tick 时只扣一个 tick。避免每台机器每 tick 单独调用无线网络。

未使用的预存 EU 在任务结束、关闭无线或拆除中心时退回原记录账户。预存余额、账户和模式写入存档，普通区块卸载不重复退款。此机制不提供跨多个 Minecraft 存档文件的崩溃原子事务保证。

## 游戏测试清单

- 客户端、服务端同时更新 JAR；先备份存档，不同时保留两个启用版本。
- 确认两个槽位各自保留物品，升级槽拒绝控制器和其他物品；重进游戏仍保留。
- 装升级、不装中央能源仓时成型；所有者打开无线后聚合任务正常运行，GUI 显示秒数及进度。
- 对比一次任务前后无线余额差与实际总功耗，任务完成后应无残留预存 EU。
- 无线余额不足时原料和进度保留，补充后继续；其他玩家不能启用中心消耗自己的电量。
- 关闭无线后由中央能源仓供电；缺少能源仓时等待供电。
- 当前任务结束后能取出升级；保存退出再加载，不重复扣已预存的电量。
- 太空组装机等级不变；涡轮等发电机无线开启时向团队电网入账，关闭时向中央动力舱/激光源仓输出。

自动化测试覆盖预存、余额不足、换账户退款、保存恢复、溢出及重复退款；不能代替游戏内 GUI、结构成型和专用服务端测试。
